# Contributing

Bug reports, docs fixes, and pull requests are welcome.

1. Open an [issue](https://github.com/ibigsnet/VncBind/issues) for discussion when the change is large.
2. Prefer focused PRs against `main`.
3. Test a VM save in both form view and XML view when you change the rewrite or the forwarder.
4. Keep safe defaults: VNC listens on 127.0.0.1 and is opened only on addresses you check.

Support: [GitHub Issues](https://github.com/ibigsnet/VncBind/issues).
